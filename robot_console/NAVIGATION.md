# 地图定位与导航使用说明

本版用于ROS2 Humble和当前wheels-v2固件。Nav2、AMCL、地图服务、Simple Commander与robot_localization已安装在树莓派的ros2-humble容器。现阶段直接使用现有编码器+IMU里程计，没有另外启用EKF。地图、激光、车体、路径和鼠标选点均在Windows上位机本地实现；树莓派传输二维坐标数据，日常导航不需要运行RViz或VNC，也无需安装Windows版ROS2。

## 启动顺序

1. 关闭旧版上位机，打开本目录的RobotConsole.exe，连接树莓派。
2. 在“总览与遥控”选择/dev/ttyAMA3，点击“打开底盘串口”，确认有wheels-v2、轮速和电压反馈，先不要点击遥控使能。
3. 进入“地图与导航”，停止原建图及远程RViz。建图和地图定位导航不能同时运行。确认地图已经保存后再停止建图；可展开“远程RViz / VNC”停止旧窗口，新的会话通常不需要启动它。
4. 点击“启动雷达”，再点击“启动地图定位导航”。若雷达已由本会话启动，不要重复启动。
5. 地图会直接显示在本页；用“适配地图”“放大+”“缩小−”或本地鼠标滚轮调整视图。左键平移，或在任何模式下用右键拖动平移。收不到地图时可点“刷新地图”。
6. 停车状态下点击“设置初始位置”，在地图中小车实际位置按住左键，拖出车头方向后松开。等待红色激光与墙线重合、蓝色车体位置符合实际，并显示定位与底盘就绪。拖动过短、地图外、未知区和占据栅格均不提交。
7. 点击“允许自主控制”，再点击“设置导航目标”，在空闲位置按住左键拖出最终车头朝向后松开。树莓派直接调用NavigateToPose，无需经过RViz工具或面板。界面先确认收到选点，再显示Nav2接受、执行和最终结果。
8. 第一轮选约30厘米的空闲目标。自主行驶时遥控禁用；点击“取消导航并停车”或底部“禁能 / 停止遥控”立即撤销底盘使能并取消目标。
9. 到达目标后，等待真实轮速连续接近零，再显示“已到达并停稳”。下一次任务需要再次点击“允许自主控制”。若定位不正确，不要继续授权。

## 当前配置和范围

- 使用固定地图/workspace/ros2_ws/maps/console_map.yaml，不会自动覆盖它；地图切换和命名地点管理尚未加入。
- 车体按25厘米长、20厘米宽，外形附加2厘米余量。雷达按车体中心、零度朝车头配置，这只是用户确认的初始假设，未做安装标定。
- 最大线速度0.08米/秒，最大角速度0.4弧度/秒；目标容差6厘米、约8.6度是控制判据，不是实测定位精度保证。
- 自主模式临时关闭原直行yaw锁定，由Nav2统一控制航向；退出后恢复原yaw_enabled设置。原四轮速度PI和舵机接口保持不变。
- Nav2中间速度/nav_cmd_vel_raw只进入平滑器，最终/nav_cmd_vel经过授权和超时检查，再转换为现有带时间戳的底盘命令。手动遥控不能同时控制底盘。
- 本版导航由当前上位机会话管理。关闭上位机或SSH断开被检测后，撤销使能并回收本会话程序；串口命令超时还受现有底盘与STM32保护。没有配置开机自动行驶或断线后继续任务。
- 点击自主控制前应先停止机械臂/舵机调整，确认突出机构没有超出当前车体轮廓。地图中雷达扫描高度看不到的障碍不会自动成为可避障物体。
- 叠加画面以5Hz传输，地图图像在Windows缓存。缺少真实TF、激光时间变换未就绪或数据超时，会隐藏相应叠加层并显示原因；历史地图可保留查看，但不能当作实时定位。蓝色为真实车体位置，黄色箭头只是人工选点。
- Windows版同时保留“原始激光预览”，可在没有地图定位时检查雷达自身坐标扫描。该预览与地图叠加显示区有不同坐标含义。

## 建图模式

需要重新建图时，先取消自主控制、停止导航程序，再启动原“纯雷达建图”；地图也在Windows显示，不必打开RViz。两种模式的TF发布互斥。建图时仍在“总览与遥控”按住方向按钮驾驶。

## 可选远程RViz

仅在需要完整ROS调试面板时展开“远程RViz / VNC”，启动树莓派上的导航RViz并通过现有RealVNC查看。它仍会消耗树莓派图形渲染资源。导航配置已包含Navigation 2面板，普通Windows导航不依赖该面板。
