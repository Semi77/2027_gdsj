# 2026-10-29 扩展：累计编码器与PA8舵机

原wheels-v2标识0xC202和type=0x02四轮指令保持不变，新增以下可选能力，由0x82能力位识别。

### 舵机控制 type=0x03，负载8字节 `<IBBH`

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u32 | 已由四轮禁能帧同步的非零session |
| 4 | u8 | 舵机通道，当前仅0（PA8） |
| 5 | u8 | enable，0关闭、1输出 |
| 6 | u16 | 脉宽μs；enable=0必须0，enable=1允许500..2500 |

舵机单独记录header序号和确认，不改变车轮确认序号，不刷新车轮超时。新session首条舵机命令可使用任意序号，之后按16位差值1..32767接收，重复和倒序拒绝。通信失联、车轮禁能时保持最后PWM；仅明确关闭或MCU复位后关闭。

### 扩展反馈 type=0x82，负载32字节 `<II4I4H`

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u32 | 编码器采样时间ms，32位回绕 |
| 4 | u32 | 当前控制session，复位初始0 |
| 8 | u32×4 | A/B/C/D累计编码器，带方向增减、无符号模2^32回绕 |
| 24 | u16 | 能力：bit0累计编码器、bit1PA8舵机、bit2故障反馈 |
| 26 | u16 | 故障：bit0欠压、bit1接收错误历史、bit2车轮超时、bit3IMU未就绪 |
| 28 | u16 | 当前舵机输出脉宽，0关闭；不是实际位置回读 |
| 30 | u16 | 最近接受的舵机指令序号 |

0x81与0x82采用同一反馈序号，CRC分别计算，打包为一次非阻塞UART发送，总106字节。计数和采样时刻在同一临界区复制。主机按相邻累计值模差还原有符号增量，不能直接把无符号原值当绝对距离。

# 当前执行接口 wheels-v2（2026-10-28）

帧版本仍为 1，CRC 与反馈布局不变。新固件只接受 **type=0x02，负载13字节**：

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u32 | 非零会话 ID |
| 4 | u8 | enable：0禁能、1使能 |
| 5 | i16 | A 轮目标，mm/s |
| 7 | i16 | B 轮目标，mm/s |
| 9 | i16 | C 轮目标，mm/s |
| 11 | i16 | D 轮目标，mm/s |

四轮范围各为 -300..300 mm/s，禁能时全部必须为零。零速使能握手、序号回绕和 300 ms 看门狗规则沿用。新反馈固件标识为 **0xC202**，由树莓派解码为 `wheels-v2`；UART3、反馈类型0x81及46字节布局不变。新固件不再处理 vx/wz、yaw 纠偏或左右轮分配。

树莓派 50 Hz 输出四轮指令，Windows 遥控消息20 Hz，经 ROS2 `/cmd_vel`（TwistStamped）进入控制节点；ROS2 接口及200ms有效期见 [PI_CONTROL.md](PI_CONTROL.md)。旧固件0xC201可读取反馈并发送旧零速禁能帧，但新节点拒绝对其使能；旧上位机不支持新固件。

下文旧 type=0x01 与“网关直接串口”说明保留作历史参考，不作为当前版本的控制入口。

# 调试上位机接口 v1

本文件为实现约定，尚未经硬件联调。所有串口与 ROS 传输均不应在同一接口混入任意 printf 调试文本。

## STM32 串口

USART3，PC10/TX、PC11/RX，115200/8N1，无流控，3.3 V 逻辑。树莓派使用 UART3：GPIO8/TX（物理24脚）→PC11/RX，GPIO9/RX（物理21脚）←PC10/TX，设备 /dev/ttyAMA3。GPIO4/5 留给雷达，不能选择 /dev/ttyAMA2。

帧：`AA 55 | version:u8 | type:u8 | payload_length:u16 | sequence:u16 | tick_ms:u32 | payload | crc:u16`

全部多字节字段为**小端**。头部含魔数共12字节，CRC2字节，负载上限80字节。CRC16/CCITT-FALSE：poly=0x1021、init=0xFFFF、refin/refout=false、xorout=0；校验从 version 到 payload 末尾，排除 AA55 与 CRC，CRC 小端保存。字符串 `123456789` 的标准校验值为 0x29B1。

`sequence` 每方向递增并按16位回绕。MCU 用 `(uint16_t)(seq-last_seq)` 在1..32767间判断新的使能命令；重复/倒序命令不刷新超时。`tick_ms` 是发送方单调毫秒的低32位；仅用于监测，双方不将其直接当作同步 ROS 时间。MCU 独立超时根据**合法控制命令被接受的本地时间**计算。

### 旧控制，type=0x01，负载9字节（仅历史参考，新固件不接受）

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u32 | 非零会话 ID，每次网关启动随机生成 |
| 4 | u8 | enable：0禁能、1使能 |
| 5 | i16 | vx，mm/s，范围 -200..200 |
| 7 | i16 | wz，mrad/s，范围 -700..700，左转为正 |

禁能帧必须 vx=wz=0。合法禁能帧总能撤销输出并同步会话与序号，不会使能。初次和超时后，仅同会话、更新序号、零速度的使能帧可以重新使能；IMU 必须就绪。使能后允许非零速度。CRC、长度、版本、范围、会话或序号错误均不刷新300ms看门狗。无独立心跳续命。

禁能输出和普通零目标不同：普通使能下零目标保留闭环，禁能撤销驱动 STBY 并在控制周期清除 PI 历史。实际机械制动效果由驱动硬件决定，必须实测。

网关初值20Hz发送，GUI每50ms生成带200ms截止时间的遥控请求；后台不因重复发送而延长请求期限。反馈超过200ms未更新或遥控租约到期时，网关禁能；MCU另有300ms超时。超时后人工重新使能，不自动恢复旧速度。

### 反馈，type=0x81，负载46字节

| 偏移 | 类型 | 含义 |
| --- | --- | --- |
| 0 | u16 | 新固件标识0xC202，旧版为0xC201 |
| 2 | u16 | flags：bit0使能、bit1板载IMU就绪、bit2控制命令超时 |
| 4 | u32 | 当前会话ID，尚未同步为0 |
| 8 | u16 | 最近接受命令的序号 |
| 10 | i16×4 | A/B/C/D实测速度，mm/s |
| 18 | i16×4 | A/B/C/D目标速度，mm/s |
| 26 | i16×3 | Roll/Pitch/Yaw，0.01° |
| 32 | i16×3 | 板载陀螺原始XYZ计数 |
| 38 | i16×3 | 板载加速度原始XYZ计数 |
| 44 | u16 | 电池电压，0.01V，沿用原固件电压计算 |

50Hz尝试发送，UART忙则跳过当次反馈，不堵塞控制。反馈不是累计编码器协议，不提供轮式里程计；未来导航阶段应另加累计编码器与采样时间消息，不能将本版轮速快照当作已实现的精确里程计。

板载 IMU 原始计数沿用现有 ±2000°/s、±2g 配置；姿态为原有相对零点解算，未做新的磁航向校准。后续选择外接 IMU 后通过独立 ROS 话题接入，不能套用板载量程。

## K230 串口预留

使用另一条独立 USB TTL 链路，初始115200/8N1。发送UTF-8 JSON对象，一帧结果一行，LF结束；单行最多65536字节，至多100个检测。模型可改变类别表，不改变传输格式。

```json
{"version":1,"frame_id":123,"width":640,"height":480,"fps":25.4,"detections":[{"class_id":0,"label":"示例类别","cx":320.5,"cy":240.0,"confidence":0.93}]}
```

上例仅说明结构，不是实测数据。`frame_id` 为非负帧序号；`width/height` 为正整数原图尺寸。`cx/cy` 是原始图像像素坐标，左上为原点，X向右、Y向下；模型缩放/裁剪/letterbox后的坐标应由K230先还原。中心坐标不是三维空间坐标或车体距离。`confidence` 范围0..1，`fps` 非负且有限。没有目标时仍发 `detections:[]` 表示正常处理了一帧，不以沉默表示“无目标”。

K230桥只被动接收，校验后发布ROS `/k230/detections_json`，`std_msgs/String`；上位机收到后显示表格。JSON行格式暂不加二进制CRC，也不承载运动命令；若以后提高串口速率或需要更强丢包检测，可另加传输层版本，不能无提示混改格式。

## ROS接口

| 话题 | 类型 | 用途 |
| --- | --- | --- |
| `/imu/data`、`/imu/data_raw` | sensor_msgs/Imu | 角速度rad/s、加速度m/s²、四元数；姿态协方差首项-1表示无姿态 |
| `/scan` | sensor_msgs/LaserScan | 激光自身坐标显示，SensorData QoS |
| `/map` | nav_msgs/OccupancyGrid | transient-local二维地图；本版不叠加未校验TF的激光 |
| `/k230/detections_json` | std_msgs/String | 上述检测JSON对象 |
| `/pi/results_json` | std_msgs/String | 任意JSON对象，最大65536字节，10Hz显示上限 |

上位机当前遥控走网关到STM32的受限协议路径，**不发布 `/cmd_vel`，不是 Nav2 控制桥**。后续接Nav2前必须实现统一速度仲裁、ROS底盘桥和完整里程计，不能再增加第二个同时写USB串口的程序。
